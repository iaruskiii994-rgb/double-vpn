# DOUBLE VPN

Бесплатный VPN на Python: публичные серверы (до 1000) (VLESS / VMess / Trojan / Shadowsocks / Hysteria2)
со смешными русскими названиями вроде `🇩🇪 ТУРБОВПН ГЕРМАНИЯ БЕРЛИН КЛАСИК` и `🇷🇺 ОБХОД БЕЛЫХ СПИСКОВ РОССИЯ МОСКВА`
(флаг — страна, где сервер на самом деле выходит в интернет).
Внутри работает ядро [Xray](https://github.com/XTLS/Xray-core): при первом запуске оно само скачивается в `core/`
с официального GitHub (сверяется SHA-256).

Нужен только Python 3.10+ — сторонние библиотеки не требуются.

## Запуск

```
python vpn.py        # окно программы (или двойной клик по run_vpn.bat)
python collect.py    # собрать заново рабочие серверы из консоли
```

- **⚡ АВТО** — первая строка списка (и первый пункт в подписке для Happ). В пуле — 30 самых быстрых
  зарубежных серверов, причём только те, что выдержали длинную загрузку 3 МБ без просадки скорости.
  Xray пингует их каждые 30 с, помнит последние 6 замеров, выкидывает часто не отвечающие и медленнее 1.5 с
  и держит трафик на **двух самых стабильных** (с наименьшим разбросом задержки), раскидывая соединения
  между ними: если один сервер просел, страдает только часть соединений, а АВТО быстро переключается.
  В АВТО берутся только прямые зашифрованные соединения (tcp/xhttp + reality/tls): gRPC, WS через Cloudflare
  и нешифрованные на бесплатных серверах отвечают на пинг, но рвут длинные загрузки.
  Серверы с выходом в России и обход белых списков в АВТО не попадают. Работает и с DOUBLE VPN.
- **📱 Другие устройства** — ссылка-подписка для Happ и любых других клиентов + QR-код:
  - 🌐 **для Happ** (`happ.json`, а также первая ссылка `double_vpn.txt`) — первым идёт «⚡ АВТО (самый быстрый)»:
    Happ раз в минуту пингует 30 самых быстрых зарубежных серверов и ведёт трафик через лучший. Дальше —
    зарубежные серверы по скорости, потом с выходом в России, «ОБХОД БЕЛЫХ СПИСКОВ» — в конце.
    У каждого сервера флаг страны. Формат — Xray JSON (как в шаблонах Remnawave). Если Happ сам
    пересортировывает список — в настройках Happ выбери сортировку «без сортировки».
  - 🌐 **для других приложений** (`links.txt`) — обычные ссылки в том же порядке с флагами, но без «АВТО».
  - обе ссылки в интернете работают на любом устройстве и в любой сети (мобильный интернет, другой город),
    даже когда компьютер выключен. Подписка лежит в твоём секретном GitHub Gist, программа сама обновляет её
    после каждой проверки/сбора. Доступ к GitHub берётся из входа git (Git Credential Manager) —
    токен нигде не сохраняется; если git не залогинен, можно один раз вставить токен с правом `gist`.
    В `core/github.json` лежат только id Gist и ссылка.
  - 🏠 **в домашней сети** — `http://<IP компьютера>:10830/sub` (для Happ — `/happ`), пока программа запущена.
  - «📲 Ссылка «добавить в Happ»» — `happ://add/…`: отправь себе в Telegram и нажми на телефоне.
  В Happ / v2rayNG / Hiddify / Streisand / v2rayN: «+» → добавить подписку или сканировать QR.
  При первом открытии Windows может спросить про брандмауэр — разреши Python, в том числе для общедоступных сетей.
- **ПОДКЛЮЧИТЬ** (или двойной клик по строке) — включает VPN через выбранный сервер.
  С галочкой «Системный прокси Windows» через него идут браузеры и большинство программ;
  при отключении/закрытии прежние настройки прокси возвращаются.
- **Российские сайты напрямую** — `.ru`/`.рф` и российские IP идут мимо VPN.
- **DOUBLE VPN** — выбери первый хоп в выпадающем списке: трафик пойдёт *ты → хоп 1 → выбранный сервер → интернет*
  (hysteria2 в цепочке не работает). Стыкуется примерно половина пар: часть бесплатных серверов
  не пускает подключения с других серверов. Если пара не заработала, возьми другой первый хоп —
  лучше всего цепляются vless reality.
- **Проверить серверы** — перепроверяет все серверы из твоей сети: пинг и загрузка 256 КБ через каждый.
  Многие бесплатные серверы отвечают на пинг, но зависают на настоящем трафике — такие становятся серыми с ✗.
  Колонка «Мбит/с» — скорость загрузки (у 100 лучших замерена точно, у остальных — примерно).
- **Колонка «Транспорт»** — `tcp+reality`, `ws+tls`, `xhttp+reality`, `grpc`, `hy2`…; в поиск можно вписать `xhttp` или `ws`.
- **⬇ Собрать → Собрать заново (до 1000)** — качает публичные списки (≈260 тыс. ссылок) и проверяет каждый сервер пингом
  и загрузкой, не дольше 25 минут. Уже найденные рабочие перепроверяются первыми.
  Работающих из России бесплатных серверов обычно набирается сотни, а не тысяча — мёртвые в список не попадают.
- **⬇ Собрать → Добавить обход белых списков (выход за границей)** — серверы из подборок для белых списков
  (igareck, zieng2, ByeWhiteLists, goida 26 и др.): вход через российские сети/SNI из белых списков,
  а выход в интернет — за границей. Серверы белых списков с выходом в России помечаются как обычные.
  Из консоли: `python collect.py --white`.
- **⬇ Собрать → Добавить серверы xhttp и WS** — не трогая текущий список, ищет и добавляет рабочие серверы
  только с транспортом xhttp и WebSocket (то же из консоли: `python collect.py --add xhttp,ws`).
- **Ссылка** — копирует `vless://…` с красивым названием для v2rayN / Hiddify / Happ / v2rayNG.
  Все ссылки разом лежат в `servers_sub.txt` — его можно импортировать в телефон.

Другим программам VPN доступен как SOCKS5 `127.0.0.1:10828` и HTTP `127.0.0.1:10829`.

**Не включай одновременно другой VPN в режиме TUN** (Happ, v2rayN, Hiddify…): тогда трафик идёт через
два VPN подряд — медленно, а проверка серверов показывает не то, что будет без него.
Программа сама замечает такой VPN и показывает красную плашку.

## Автообновление (чтобы в Happ не было «н/д»)

Бесплатные серверы живут от часов до нескольких дней, поэтому подписку обслуживает **облако GitHub**
(GitHub Actions, файл `.github/workflows/refresh.yml`) — круглосуточно, компьютер для этого не нужен:

- **каждый час** — лёгкая проверка (~1 мин): пинг всех серверов, умершие сразу уходят из подписки,
  пулу «⚡ АВТО» перемеряется скорость;
- **раз в 6 часов** — полное обслуживание (~15 мин): перепроверка загрузкой и добор новых серверов;
- свежий список сохраняется в `servers.json` этого репозитория, подписка (Gist) обновляется по той же ссылке;
- адрес подписки и доступ к Gist лежат в зашифрованных секретах репозитория (`GIST_ID`, `GIST_TOKEN`),
  в коде и публичных логах их нет;
- запустить вручную: вкладка Actions → «Обновление серверов» → Run workflow (галочка — полное обслуживание).

Программа на ПК в этом режиме сама ничего не публикует, а раз в час забирает свежий список из облака
(галочка внизу окна). Кнопки «Проверить серверы» и «Собрать» работают как раньше — для своего списка на ПК.

В подписку попадают **только лучшие**: 250 самых быстрых серверов с пингом до 2.5 с и 30 лучших
«обход белых списков». В Happ включи «Настройки → Подписки → Обновлять при открытии» — тогда при каждом
запуске будет свежий список.

## Откуда серверы

Только открытые публичные подборки на GitHub, сначала российские (igareck/vpn-configs-for-russia,
kizyak-vpn, goida-vpn-configs, RKP_bypass_configs и др.), затем мировые агрегаторы.
Зелёные строки `OBHOT WHITE SPISOK` — конфиги из подборок для обхода белых списков.

Бесплатные серверы живут от часов до дней: чем старше список, тем больше серых строк —
тогда жми «Собрать заново». Трафик через чужие бесплатные серверы не приватен:
не входи через них в банк и важные аккаунты.
